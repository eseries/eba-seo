Automatically generates JSON-LD schema markup for better SEO and rich results.

== Description ==

Eba SEO makes it easy to add structured data to your WordPress site without coding.

The plugin automatically outputs valid JSON-LD schema on your posts, pages, and custom post types. This helps search engines understand your content and can lead to rich results like stars, FAQs, and more.

**Features:**
* Automatic JSON-LD output for Posts and Pages
* Clean, lightweight code with no bloat
* Valid schema.org markup
* Works with any theme
* No settings required to start

More schema types coming soon.

== Installation ==

1. Upload the `auto-json-ld-wp` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. That's it! Schema is now added automatically

== Frequently Asked Questions ==

= Does this work with Yoast/RankMath? =
Yes. This plugin adds basic schema. If you use another SEO plugin, test to avoid duplicate schema.

= Can I customize the schema? =
Version 1.0.0 outputs automatic schema. Customization options are planned for future updates.

= Is it lightweight? =
Yes. The plugin only outputs the JSON-LD script and has minimal impact on performance.
