# Eba SEO

Lightweight WordPress plugin that auto-generates JSON-LD schema markup for better SEO and Google rich results. No config needed.

### Features
- Automatic JSON-LD for Posts, Pages, CPTs
- Valid schema.org markup
- Lightweight - no bloat
- Works with any theme

### Install
1. Upload to `/wp-content/plugins/`
2. Activate
3. Schema is live
